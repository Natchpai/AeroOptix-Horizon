# Documents

Supporting documents for the AO-Horizon KiCad project.

- `design/`: specification, execution checklist and design records (Markdown). See `design/README.md`.
- `images/`: images and branding assets.
- `manufacturing/`: manufacturing outputs and assembly information.
- `reference/`: third-party reference files, not design data. `px4-matek-h743-slim/` holds the PX4 Matek H743-Slim board port.
- `schematic/`: schematic documentation.
- `verification/`: verification records.
